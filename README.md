# Mojobase skills for Claude

A plugin of skills that teach Claude real jobs in your business through [Mojobase](https://mojobase.ai): the
morning run-through, chasing who owes you, preparing for a call, the week's review and your business profile.

What each skill does, and how to install it in claude.ai, Claude Desktop and Claude Code:
[plugins/mojobase/README.md](plugins/mojobase/README.md).

```
/plugin marketplace add mojobase/skills
/plugin install mojobase@mojobase
```
